# Archivo TIC IA — Agente Documental Inteligente

Proyecto académico desarrollado para la **Práctica 2.3 de Inteligencia Artificial Aplicada a las TIC**, cuyo objetivo es consultar documentos de Google Drive mediante Inteligencia Artificial.

## Objetivo

Desarrollar un agente documental capaz de consultar archivos PDF, DOCX y TXT, utilizando búsqueda semántica (RAG) para generar respuestas basadas en los documentos indexados.

## Funcionalidades

- Consulta de documentos mediante Inteligencia Artificial.
- Integración con Google Drive y OpenAI.
- Respuestas con referencias a los documentos utilizados.
- Visualización de archivos indexados.
- Sincronización manual y automática mediante GitHub Actions.
- Interfaz web adaptable a dispositivos móviles.

## Tecnologías utilizadas

- **Python y FastAPI:** backend del agente.
- **OpenAI y Vector Store:** procesamiento y búsqueda documental.
- **Google Drive API:** almacenamiento de documentos.
- **HTML, CSS y JavaScript:** interfaz web.
- **GitHub Actions:** automatización de la sincronización.
- **Vercel y GitHub Pages:** despliegue del proyecto.

## Uso del agente

1. Acceder a la aplicación web.
2. Revisar los documentos disponibles.
3. Escribir una pregunta relacionada con su contenido.
4. Consultar la respuesta generada y sus fuentes.
